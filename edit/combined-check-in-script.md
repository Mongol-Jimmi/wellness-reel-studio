# Plain-Spoken Pebble: Combined Check-In

**Format:** text-led, 25 seconds, 9:16
**Purpose:** optional general-wellness check-in combining sensory grounding and one comfortable breath
**CTA:** Save if useful

## Safety boundary

This does not claim to cure anxiety, derealization, dissociation, or stress. Stop if it feels worse. Persistent, recurring, frightening, or function-limiting symptoms warrant qualified professional support.
